## What it does

`main.py` (Python stdlib only) writes a single funny line — the funniest thing a
talking elevator would say, in the elevator's own voice — to `entry.txt` in the
output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The line is
at most 120 characters and is the same on every run.
